Repositorio asociado al Trabajo Fin de Máster del Máster Universitario en Ingeniería Computacional y Matemática (URV–UOC).

Contenido

Este repositorio contiene:

Códigos numéricos desarrollados en FreeFEM++ (.edp).

Archivos de ejecución para el clúster (.slurm).

Geometrías y mallas generadas con Gmsh (.geo, .msh y .mesh).

Los códigos implementan métodos de elementos finitos para problemas de flujo incompresible y transferencia de calor, incluyendo el método de proyección de Chorin–Rannacher, la regularización de Leray y la aproximación de Boussinesq.

Organización

codigos/: códigos fuente de FreeFEM++.

mallas/: geometrías y mallas empleadas.

cluster/: archivos de ejecución en serie y paralelo.
